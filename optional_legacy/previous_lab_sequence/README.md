# Optional Legacy Lab Sequence

The former required Labs 04-09 are preserved here for optional lecture support, individual practice, or instructor-assigned extensions. Their original numbers, deliverables, prerequisites, and launch instructions describe the previous sequence. They do not add requirements to the current course.

The required replacements are [Lab 4 - SLAM](../../lab04_slam/README.md) and [Lab 5 - Nav2 Navigation](../../lab05_navigation/README.md). Detailed background is beside each new manual.

| Former lab | Retained material | Current placement |
|---|---|---|
| [04 - Architecture](lab04_system_architecture_sensors/README.md) | TF, graph inspection, topic utility, launch illustrations | SLAM input checks and optional background |
| [05 - Sensors](lab05_sensor_characterization/README.md) | Statistics starter and uncertainty | Optional SLAM background and exercise |
| [06 - Estimation](lab06_state_estimation_localization/README.md) | Kalman-filter starter and metrics | Required Kalman starter copied into active Lab 4; archive is reference |
| [07 - Mapping](lab07_mapping_slam/README.md) | Mapping comparison | Required Lab 4 |
| [08 - Planning/tracking](lab08_planning_tracking/README.md) | A* and Pure Pursuit starters | Required Kalman starter copied into active Lab 4; archive is references |
| [09 - Integration](lab09_integration_safety/README.md) | Safety-monitor starter and fault experiments | Required safety-monitor starter and cancellation/recovery in Lab 5 |

Assigned-algorithm TODOs are preserved; no instructor solutions have been added. Run archived scripts from their own lab directory unless the manual says otherwise. Old simulation commands retain their validation notices; use the current [simulation runbook](../../docs/SIMULATION_WORKFLOW.md) for required labs.

The archive itself is optional reference material. Required Kalman, A*, Pure Pursuit, and safety-monitor starters are copied into the active labs; students must complete those versions and their new experiment specifications.
